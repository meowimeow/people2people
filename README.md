# 매칭 로직 데모

가상 프로필 20명으로 "조건 → 점수 → 순위 → 이유 설명"을 보여주는 정적 데모입니다.
모든 프로필은 가상의 인물이며 실제 사람과 무관합니다. 서버·DB·로그인은 없습니다.

## 실행

`index.html`을 더블클릭해 브라우저로 열면 됩니다. (설치 불필요)

## 파일

| 파일 | 역할 |
|---|---|
| `profiles.js` | 가상 프로필 20명 (남 10 / 여 10) |
| `matcher.js` | 매칭 엔진 (필터 → 항목별 점수 → 양방향 종합 → 설명 생성) |
| `index.html` | 화면 |

## 점수 방식

1. 필수 조건(나이 범위, 흡연, 종교, 권역)에 걸리면 제외
2. 9개 항목(나이·키·거주지·스타일·직업 안정성·대화 코드·MBTI·취미·생활/가치관)을 0~1로 채점 후, 사용자가 정한 중요도로 가중 평균 → 100점
3. 양쪽 점수의 기하평균 = 종합점수 (한쪽만 높으면 낮아짐)

MBTI는 궁합표 없이, 선호 성향(E/I·N/S·T/F·J/P)과 상대 유형의 일치 개수만 계산합니다.
외모(사진)는 점수에 반영하지 않습니다. 이 점수는 입력 조건의 일치도일 뿐 실제 궁합을 예측하지 않습니다.

## GitHub Pages로 공개

저장소 Settings → Pages → Branch를 `main` / root로 지정하면 그대로 동작합니다.
